# mduel web

A standalone browser fighting game inspired by the classic Marshmallow Duel.

The complete game is contained in a single HTML file and can be downloaded and opened directly in a modern web browser.

## Features

- Local multiplayer
- Computer opponents
- Online multiplayer
- Cross-platform online play between different devices and operating systems
- Play between smartphones, tablets, Windows PCs and other modern browser-capable devices
- Direct browser-to-browser gameplay via WebRTC
- Decentralized rendezvous using Nostr/WSS relays
- Invitation links and QR codes
- Manual server-independent WebRTC connection
- Standalone single-file version
- No installation required

## Cross-platform play

mduel web is designed to work across different platforms.

For example, an online match can be played between:

- a smartphone and a Windows PC
- two smartphones
- a tablet and a desktop computer
- Windows, Linux or macOS computers
- other devices with a compatible modern web browser

The players do not need to use the same operating system or device type.

## Play

Download the latest `.htm` file and open it in a modern browser.

For online matches, public or user-configured rendezvous services are used only to establish the connection between the players. The actual match runs directly between the browsers using WebRTC.

## Privacy

The game does not require a central player account.

Online connections are established using decentralized rendezvous infrastructure. Gameplay traffic is transferred directly between the participating browsers after the WebRTC connection has been established.
